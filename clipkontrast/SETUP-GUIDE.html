ClipKontrast

Setup Guide

Lambi videos aur streams se captions wale vertical clips (Reels, Shorts, TikTok) banao, apne hi PC pe. Free hai, koi sign-in nahi.

Guide by @anistroz.ai @anistrozelite

Kya chahiye

  • Windows 10/11 ya Mac (Linux bhi chalega)
  • 8 GB RAM ya zyada (16 GB ho toh lambi streams aur aaram se)
  • Lagbhag 3 GB khaali jagah, aur internet
  • Python, ffmpeg jaisi cheezein khud install karne ki zaroorat nahi: start file ye sab apne aap kar deti hai

Windows pe setup (5 steps)

1

ZIP download karo

Jo ClipKontrast.zip link diya gaya hai, use download karo.

2

Chhote folder mein extract karo

ZIP pe right-click karo, phir Extract All. Folder ko C:\ClipKontrast jaisi chhoti jagah pe rakho.

Zaroori: folder ko bahut gehre folders ke andar mat rakhna. Windows lambe path pe speech model load nahi kar paata aur error aata hai: "DLL load failed ... too long".
3

Start-ClipKontrast-Windows.bat pe double-click karo

Agar blue screen aaye "Windows protected your PC", toh More info pe click karo, phir Run anyway. Ye isliye aata hai kyunki file internet se aayi hai.

4

Pehli baar thoda wait karo (5-10 minute)

Kaali window mein script khud ye sab karegi:

  • Python aur ffmpeg install karegi (agar pehle se nahi hain)
  • Zaroori packages install karegi
  • Speech model download karegi (lagbhag 480 MB, sirf ek baar)

Phir browser apne aap khul jayega aur ClipKontrast ka dashboard dikhega.

Jab tak app use kar rahe ho, ye kaali window khuli rakhna. Window band karoge toh app bhi band ho jayega.
5

Free AI key daalo (2 minute, zaroor karo)

AI key ke bina bhi clips bante hain, lekin sirf awaaz ki loudness dekh ke. AI key ho toh AI baat-cheet samajh ke best moments chunta hai, aur hook aur titles bhi likhta hai.

  1. aistudio.google.com/apikey kholo, Google account se login karo, aur Create API key dabao.
  2. ClipKontrast mein Settings (neeche left) pe jao, phir AI.
  3. AI service: Gemini chuno. Key wale box mein key paste karo.
  4. Find models dabao aur koi flash model chuno, jaise gemini-2.5-flash.
  5. Save and test dabao. Test pass ho gaya aur sidebar mein "AI: Not set up" hat gaya, toh AI ready hai.

Clips kaise banaye

  1. Home pe YouTube, Twitch ya Kick ka link paste karo, ya Upload video se apni file daalo.
  2. Options mein chuno: kitne clips chahiye, clip ki length, caption style (Bounce, Hype, Clean) aur layout. Gaming streams ke liye Gameplay + facecam layout achha lagta hai.
  3. Make clips dabao.
Lambi streams (20 minute se zyada): ClipKontrast pehle poori stream scan karta hai, uske lively hisse sunta hai, aur phir poori stream ke best clips ek saath deta hai. Isliye pehla clip thodi der baad dikhega, lekin clips poori stream ke best honge.

Clips ban jaane ke baad har clip pe score (0-100), hook aur title dikhega. Har clip ko download kar sakte ho, ya Settings, Connected apps mein YouTube/Instagram/TikTok jod ke seedha post bhi kar sakte ho.

Agli baar se

Bas Start-ClipKontrast-Windows.bat pe double-click karo. Kuch hi second mein browser khul jayega. Agar ClipKontrast pehle se chal raha ho, toh script seedha browser khol degi.

Mac aur Linux

Mac

  1. ZIP pe double-click karo aur folder ko apne home folder mein rakh do.
  2. Start-ClipKontrast-Mac.command pe right-click karo, phir Open, phir dobara Open. Ye sirf pehli baar karna hai.
  3. Agar Homebrew nahi hai toh brew.sh se install kar lo. Script usse Python aur ffmpeg khud le aayegi.

Linux

  1. ZIP extract karo.
  2. Folder mein terminal kholo aur chalao: bash start-linux.sh
  3. ffmpeg na ho toh: sudo apt install ffmpeg

Naya version aaye toh update kaise karein

  1. ClipKontrast ki kaali window band karo.
  2. Naya ZIP usi folder mein extract karo aur files replace kar do.
  3. Start file dobara chalao.

Tumhari videos aur clips (data folder) safe rehti hain, kyunki wo ZIP ka hissa nahi hain.

"DLL load failed ... too long"Folder ko C:\ClipKontrast pe le jao aur dobara chalao.
Python install hone ke baad errorWindow band karo aur start file dobara double-click karo.

Mac: "cannot be opened"Double-click ki jagah right-click karo, phir Open.
